# 🛒 BlinkIT Grocery Sales Analysis Dashboard

## 📌 Project Overview

This project analyzes BlinkIT grocery sales data using Python and Power BI.

The objective was to clean the data, perform exploratory data analysis (EDA), and build an interactive dashboard to identify sales patterns and business insights.

---

## 🚀 Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Power BI
- Jupyter Notebook

---

## 📊 Dashboard KPIs

- 💰 Total Sales
- 💵 Average Sales
- 📈 Maximum Sales
- ⭐ Average Rating

---

## 📈 Dashboard Visualizations

- Top 10 Selling Items
- Rating Distribution
- Item Weight Distribution
- Item Visibility Distribution
- Sales Distribution

---

## 📌 Key Insights

- Total Sales: ₹12.02 Lakhs
- Average Sales per Item: ₹140.99
- Highest Sale: ₹266.89
- Average Rating: 3.97/5
- Most products are rated between 4.0 and 4.5.
- Sales are concentrated among a small number of high-performing products.
